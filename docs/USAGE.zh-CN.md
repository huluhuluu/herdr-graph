# Session Graph 使用手册

[English](USAGE.md) · [返回 README](../README.zh-CN.md)

## 模式与焦点

三个概念需要分开：**会话**是一份原生历史；**轮次**是一次用户提问及其回答；**阅读方式**决定正文怎样展示。`t` 切换图的范围，`d` 切换 Family 的图形结构，`m` 切换完整／进展正文，它们互不替代。

| 阅读方式 | 显示内容 | 更新方式 | 搜索范围 |
| --- | --- | --- | --- |
| 完整输出（默认） | 所选轮次的完整问题与聚合的公开回答 | `c`、`r`，或从已更新进展切回 | 当前图中已加载的完整问答 |
| 实时进展 | 所选会话的公开助手消息，按问题分组，保留消息顺序和来源时间 | 打开期间约每 2 秒自动检查 | 聚焦进展正文时，搜索已加载窗口 |

两种方式都过滤工具内容。进展直接读取已保存的公开文字，不调用模型重新概括，不显示思考块、工具参数或工具结果。只有日志明确提供类型时才标为 Progress／Answer，其余显示 Assistant。

**按键取决于焦点。** 图有焦点时 `j/k` 移动节点、`g/G` 到首尾节点；正文有焦点时，它们控制阅读。用 `Tab` 切换，正文标题会显示 `[focused]`。宽度不足 96 列时，进展正文全宽显示，再按 `Tab` 回到图。普通完整正文少于 72 列时隐藏，Family 仍支持全宽阅读。

## 常用路径

| 目的 | 操作 |
| --- | --- |
| 查看当前会话 | 从 agent 窗格打开插件，按 `c` |
| 跟随当前执行的进展 | `c` → `m`，正文有焦点时按 `G` |
| 查找历史会话 | `s` → 选择目录并按 Enter → 选择会话并按 Enter；也可直接 `m` 预览进展 |
| 查看完整问题和回答 | 选择轮次，`Tab` 聚焦正文；进展中按 `m` 返回完整方式 |
| 查看会话分支 | 选中会话按 `f`，再按 `d` 查看详细轮次树 |
| 返回原来的页面 | `Backspace`／`Esc`，保留筛选、折叠、阅读方式和位置 |
| 关闭 | 浏览时 `q`；任意状态 `Ctrl+C` |

已有弹窗中的 JavaScript 不会随仓库更新自动替换。升级或修改代码后关闭旧弹窗，再重新打开，无需重启 Herdr。

## 当前会话与正在查看的会话

绿色 `[current]` 表示**打开插件的调用窗格的当前会话**，显示在图的 branch/forks 附近，选中行也保留绿色。它不表示鼠标或光标正选中的会话，也不表示该会话此刻一定在执行。

优先使用 Herdr 上报的原生会话 ID。缺失时，以 agent、目录、完整终端标题做唯一精确匹配；扫描中一旦匹配即可标记，后续出现歧义会撤销。`c` 会重新检查调用窗格；无法确认身份时提示原因，保留原页面。

浏览其他会话不会改变 `[current]`。调用窗格执行 resume、切换原生会话后，也不会悄悄替换正在阅读的历史；需要跳到新的当前会话时按 `c`。原生在线状态约每 5 秒更新，正文跟随采用独立的约 2 秒检查。

## 实时进展

### 跟随与暂停

- 从会话标题进入进展时默认看最新；从历史轮次进入时定位该轮。该轮没有公开助手文字时会明确说明，不拿后面的答复代替。
- 正文停在底部时跟随新增消息。向上滚动或搜索会暂停，显示新消息数量；同一消息的状态更新不算新消息。
- 正文有焦点时按 `G`／`End` 加载最新窗口并恢复跟随，旧的历史请求不会覆盖这次操作。
- `m` 切换两种阅读方式，各自保留位置；返回已读会话时按消息恢复书签，早期消息会按需重新加载。窗口缩放后尽量保持同一段文字可见。
- `r` 立即重新校验所选日志，必要时重新扫描该会话，不扫描全部历史。完整方式中的历史会话标题尚未打开正文时，请先 Enter，或用 `m` 直接阅读进展。

普通检查约每 2 秒一次。同步失败后按约 4／8／16 秒退避，最长 16 秒；`r` 可提前检查。没有新文字不等于任务卡住或完成，任务状态只使用日志明确提供的信息。

### 历史分页与搜索

初始窗口通常为最新 200 条，合并历史窗口最多 400 条。到顶部继续上翻会读取上一段；到底部继续下翻会读取下一段，因此可连续阅读中间历史。`g` 请求最早消息，`G` 回最新。窗口大小限制不会删除原始记录。

在聚焦的进展正文中按 `/` 搜索当前窗口，不修改图的筛选；先翻到需要的历史再搜索。图有焦点时 `/` 沿用该图的历史／问答搜索。`p` 切换全部助手文字／仅明确分类的进展，筛选只影响显示。

`p` 后显示“No classified progress”通常说明该窗口没有可靠的类型字段；按 `p` 返回全部助手文字。旧 Codex、Claude 或 DST 记录未必提供类型，不能根据最后一条文字猜测最终答复。

### 状态说明

| 提示 | 含义与处理 |
| --- | --- |
| Loading progress | 正在初始化所选日志；大文件首次需要流式扫描 |
| Following latest | 正在跟随最新窗口 |
| Paused / N new | 阅读旧内容，新消息已计数；正文中按 G 恢复 |
| No public assistant progress | 尚无可展示的公开文字；工具运行输出被过滤 |
| No public assistant message … selected turn | 所选轮次没有助手消息；可以切回完整问题或按 G 看最新 |
| Sync failed / previous snapshot | 同步异常，仍显示最后成功内容；检查权限、日志位置或按 r 重试 |
| Log replaced … previous snapshot | 文件被替换，等待新日志中的完整公开消息 |
| Updating full output | 切回完整方式后正在补齐；暂时保留上次快照 |
| Saved message … no longer available | 重写后的日志不再包含该书签，退回可用窗口 |

工具长时间运行、agent 空闲后重新执行、最后一条答复在 idle 后才落盘，都不会停止进展订阅；关闭进展才停止跟随。关闭调用 pane 不妨碍继续阅读已有本地文件。

## 历史与分支

`s` 默认按目录分组，仅展开调用窗格所在目录。`a` 循环 agent 筛选，`v` 切换目录／时间列表，`o` 反转修改时间排序，`/` 搜索标题和路径。统计按 agent 内的原生 ID 去重，包含 Codex 归档会话；不可读文件保留错误条目，不中断其他会话扫描。

`f` 打开共同祖先下的完整 Family，包括同级分支；`d` 切换一行一个会话的结构图和详细轮次树。`T` 显隐来源时间，`h/l` 折叠／展开分支。详细树显示共享历史一次，保留原会话的轮次编号；进展正文开启时也能加载详细树。

连线来自原生父 ID，`[turn N]` 按直属父会话完整历史编号。时间采用 UTC 来源时间，不用文件修改时间冒充分叉时间。缺失父文件、未知锚点、加载中和读取失败分别标注，不按话题相似度猜关系。

结构图的 Enter 在会话标题上打开完整会话；详细 Family 轮次的 Enter 聚焦正文；普通完整对话轮次的 Enter 跳转到已运行的匹配会话窗格。进展正文有焦点时 Enter 返回完整方式。

## 恢复、分叉与改名

| 操作 | Codex | Claude Code | DST |
| --- | --- | --- | --- |
| `n` 恢复 | `/resume <ID>` | `/resume <ID>` | 打开原生 `/resume` 选择器，需手动选会话 |
| `F` 分叉 | 复制完整已保存会话，再切换到子会话 | 当前会话 `/branch` | 插件不提供 |
| `R` 改名 | App Server 原生名称 | 原生 title 记录与 sidecar | 原生持久化 title 事件 |

恢复和分叉只使用打开插件的原 agent 窗格，要求同类 agent、空闲状态、输入框为空；不新建 pane。已在其他窗格运行的会话会拒绝重复恢复。Codex 分叉复制完整保存历史，选中旧轮次只改变预览，不形成“从该轮精确分叉”。Claude 分支要求先恢复所选会话，并支持原生 `/branch`。

改名输入中 `Ctrl+U` 清空，Backspace 按 Unicode 字符删除，Enter 保存，Esc 取消。改名不启动模型 turn；运行中的原生客户端可能需要重新打开／恢复才能刷新名称。DST 写租约被占用时拒绝改名。

Codex 初始化与元数据操作各有 60 秒期限（关闭辅助进程前最多等待 120 秒），通知消息不会延长期限。分叉只提交一次，不自动重试；超时不证明子会话尚未保存，重复操作前请先检查原生历史。请求也会通过 `deferGoalContinuation` 延后初始 goal 自动续跑，需要 CLI 支持该字段。

## 存储、限制与排查

只读取运行插件这台机器上的历史，SSH 远端不会自动与本机合并。根目录、安装维护命令见 [README](../README.zh-CN.md)。安装保存自定义 agent 根目录，显式环境变量优先，弹窗启动前固定这些根目录以抵抗 shell profile 改写。

单条 JSONL 记录、压缩帧及单帧解压上限为 64 MiB；超限显示错误。旧正文按位置读取，不把完整工具输出保存在进展模型。快速批量追加优先更新所看窗口和最新片段，原始历史仍可分页，未读计数不按截取后的条数少算。

| 现象 | 检查 |
| --- | --- |
| 新进展没有出现 | 确认当前是进展方式、跟随对象正确；看是否 Paused；源日志是否已经落盘；按 r 检查错误 |
| 完整方式没有持续新增 | 自动跟随属于进展方式；用 m，或 c/r 显式刷新完整方式 |
| current 缺失 | 从实际 agent 窗格打开，检查原生 ID；目录＋标题回退必须唯一 |
| 只有工具在运行，正文没变化 | 工具信息被过滤，需等待公开文字落盘 |
| 历史总数不对 | 检查 agent 筛选、自定义根目录、归档路径和具体条目的读取错误 |
| 快捷键不能打开插件 | 看安装是否启用；用 `node src/graph.js open`；K 仅显示绑定说明，不修改配置 |
| 更新后仍是旧界面 | 关闭旧弹窗再打开；维护命令要求干净 Git 工作区和正常上游 |

缓存只保存派生解析结果，`clean` 不删除原生会话。macOS 尚未完成本项目的原生运行验证。架构、当前限制及验证命令见 [开发说明](DEVELOPMENT.md)。
